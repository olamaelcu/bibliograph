# Bibliograph

A collection of tools for bibliographic work in one project:

- An [ATProto AppView][1] for resolving book information

## Setup

```bash
pnpm install
pnpm run dev   # Vite dev server with Hono as middleware on http://localhost:5176

# Or use `mise`
mise dev
```
